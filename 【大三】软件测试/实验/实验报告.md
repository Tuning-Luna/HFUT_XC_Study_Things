# 软件自动测试工具综述报告

随着软件系统规模变大、迭代变快，靠人工测试已经很难保证质量了。为了解决这个问题，自动化测试工具通过脚本、框架和持续集成等方式，让测试效率和覆盖面都得到了很大的提升。下面我会分析一下目前主流工具的分类和现状，了解 **JUnit、Selenium、Jest** 和 **Postman** 的核心原理及用法。



### JUnit — Java 单元测试框架

JUnit 是 Java 生态中最经典的单元测试框架，由 Kent Beck 和 Erich Gamma 共同创建。当前主流版本为 **JUnit 5**（Jupiter），采用模块化架构，支持参数化测试、扩展机制和条件执行等高级特性。

**核心特点：**

- 注解驱动（`@Test`、`@BeforeEach`、`@ParameterizedTest` 等）
- 与 Maven/Gradle 无缝集成
- 支持与 Mockito 配合进行依赖隔离
- 丰富的断言库（`Assertions` 类）

基本使用示例

**被测类：**

```java
public class Calculator {
    public int add(int a, int b) { return a + b; }
    public int divide(int a, int b) {
        if (b == 0) throw new ArithmeticException("除数不能为零");
        return a / b;
    }
}
```

**测试类：**

```java
import org.junit.jupiter.api.*;
import static org.junit.jupiter.api.Assertions.*;

class CalculatorTest {

    private Calculator calc;

    @BeforeEach
    void setUp() {
        calc = new Calculator();  // 每个测试方法前初始化
    }

    @Test
    @DisplayName("正常加法测试")
    void testAdd() {
        assertEquals(5, calc.add(2, 3));
        assertEquals(-1, calc.add(2, -3));
    }

    @Test
    @DisplayName("除零异常测试")
    void testDivideByZero() {
        assertThrows(ArithmeticException.class, () -> calc.divide(10, 0));
    }

    @ParameterizedTest
    @CsvSource({"2,3,5", "0,0,0", "-1,1,0"})
    @DisplayName("参数化加法测试")
    void testAddParameterized(int a, int b, int expected) {
        assertEquals(expected, calc.add(a, b));
    }
}
```



### Selenium — Web UI 自动化测试

Selenium 是目前应用最广泛的 Web UI 自动化测试框架，支持 Chrome、Firefox、Safari、Edge 等主流浏览器，并提供 Java、Python、C#、JavaScript 等多语言绑定。

```python
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.common.keys import Keys
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC
from selenium.webdriver.chrome.service import Service
from webdriver_manager.chrome import ChromeDriverManager

def test_baidu_search():
    # 初始化 WebDriver
    driver = webdriver.Chrome(service=Service(ChromeDriverManager().install()))
    driver.implicitly_wait(10)  # 隐式等待

    try:
        # 打开目标页面
        driver.get("https://www.baidu.com")
        assert "百度" in driver.title

        # 定位搜索框并输入
        search_box = driver.find_element(By.ID, "kw")
        search_box.clear()
        search_box.send_keys("软件自动化测试")
        search_box.send_keys(Keys.RETURN)

        # 显式等待结果加载
        wait = WebDriverWait(driver, 10)
        results = wait.until(EC.presence_of_all_elements_located(
            (By.CSS_SELECTOR, ".result.c-container")
        ))

        # 断言
        assert len(results) > 0, "搜索结果不应为空"
        print(f"搜索到 {len(results)} 条结果")

    finally:
        driver.quit()  # 确保浏览器关闭

if __name__ == "__main__":
    test_baidu_search()
```

**常用元素定位策略：**

```python
# By.ID        — 最快，优先使用
driver.find_element(By.ID, "username")

# By.CSS_SELECTOR — 灵活，推荐
driver.find_element(By.CSS_SELECTOR, ".login-btn")

# By.XPATH    — 复杂结构时使用
driver.find_element(By.XPATH, "//button[@type='submit']")

# By.NAME / By.CLASS_NAME / By.LINK_TEXT
driver.find_element(By.NAME, "password")
```

### Jest — JavaScript 单元测试框架

Jest 是由 Meta 开源的 JavaScript 测试框架，内置断言库、Mock 功能、代码覆盖率统计，开箱即用，无需复杂配置。广泛应用于 React、Vue、Node.js 等项目。

**核心特点：**

- 零配置启动（`package.json` 中添加 `"test": "jest"` 即可）
- 并行测试执行，速度快
- 快照测试（Snapshot Testing）
- 内置 Mock 模块（`jest.fn()`、`jest.mock()`）
- 内置代码覆盖率报告（`--coverage`）

基本使用示例

**被测模块（utils.js）：**

```javascript
// utils.js
function formatPrice(price, currency = 'CNY') {
    if (typeof price !== 'number' || price < 0) {
        throw new Error('价格必须为非负数');
    }
    return `${currency} ${price.toFixed(2)}`;
}

function fetchUserName(userId, apiClient) {
    return apiClient.get(`/users/${userId}`).then(res => res.data.name);
}

module.exports = { formatPrice, fetchUserName };
```

**测试文件（utils.test.js）：**

```javascript
const { formatPrice, fetchUserName } = require('./utils');

describe('formatPrice', () => {
    test('正常格式化价格', () => {
        expect(formatPrice(99.9)).toBe('CNY 99.90');
        expect(formatPrice(0)).toBe('CNY 0.00');
    });

    test('自定义货币符号', () => {
        expect(formatPrice(100, 'USD')).toBe('USD 100.00');
    });

    test('负数应抛出异常', () => {
        expect(() => formatPrice(-1)).toThrow('价格必须为非负数');
    });

    test('非数字类型应抛出异常', () => {
        expect(() => formatPrice('abc')).toThrow();
    });
});

describe('fetchUserName（Mock 示例）', () => {
    test('正确获取用户名', async () => {
        // 创建 Mock API 客户端
        const mockApiClient = {
            get: jest.fn().mockResolvedValue({ data: { name: '张三' } })
        };

        const name = await fetchUserName(42, mockApiClient);

        expect(name).toBe('张三');
        expect(mockApiClient.get).toHaveBeenCalledWith('/users/42');
        expect(mockApiClient.get).toHaveBeenCalledTimes(1);
    });
});
```

### Postman — API 接口测试工具



Postman 是目前最流行的 API 测试与调试工具，提供图形化界面和强大的自动化脚本能力。支持 REST、GraphQL、WebSocket 等协议，并可通过 Newman 命令行工具集成到 CI/CD 流程中。

测试脚本示例

**Pre-request Script（生成时间戳签名）：**

```javascript
// 在 Pre-request Script 标签中编写
const timestamp = Date.now().toString();
pm.environment.set("timestamp", timestamp);

// 生成签名（示例）
const sign = CryptoJS.MD5(pm.environment.get("appKey") + timestamp).toString();
pm.environment.set("sign", sign);
```
