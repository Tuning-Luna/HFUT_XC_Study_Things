## 期末

考试形式与题型可能变化，仅供参考：

- 期末考试拟采用机考方式进行。机考题型与正常考试基本一致。
- 期末考试为闭卷。考试范围为每章PPT最后一页红色高亮部分，覆盖80%以上的试卷内容。
- 机考的画图题会转换为看图解释。
- 试卷题目可设置为机改或手改，机改只改判断和选择。填空、名词解释、简答等题目，意思对即可。
- 期末考试需参加考试，缺考会导致需要补考。

期末文件夹中的真题和笔记需背诵。
