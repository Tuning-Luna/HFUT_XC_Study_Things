## 期末

附上老师原话（每年题型，考试形式有所变化，仅供参考）：

- "期末考试拟采用机考方式进行。机考题型与正常考试基本一致，正常复习即可"
- "我们期末考试因为是闭卷，难度会比课堂测试简单很多，大家不用太焦虑。考试范围就是每章ppt最后一页红色高亮的部分，会覆盖80%以上的试卷内容"
- "机考的画图题，会转换为看图解释，相对来说会更简单一些"
- "试卷题目可以设置机改还是手改的，机改只改判断和选择。填空、名词解释、简答等题目，意思对即可，不需要担心"
- "我们期末考试基本上不会难为同学，只要来考试很难不通过，希望各位班委向班里同学传达一下，能来考试的尽量来考试。不要到最后缺考导致需要补考，那就麻烦了"
