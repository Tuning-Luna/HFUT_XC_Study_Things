## 运行步骤

### 步骤一：泰山派端（需 RK3566 + 摄像头）
```bash
# 1. 启动 USB 摄像头节点
roslaunch rknn_ros camera.launch device:=video9

# 2. 启动 YOLOv5 图像识别节点
roslaunch rknn_ros yolov5.launch chip_type:=RK356X
```

### 步骤二：虚拟机端（地面站）
```bash
# 订阅泰山派发布的图像话题，实时显示
rqt_image_view
```
选择话题 `/rknn_image/theora` 查看检测结果。
