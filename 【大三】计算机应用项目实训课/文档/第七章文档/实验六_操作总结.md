## 完成内容

### 步骤一：PWM 控制初始化 ✅（已预置）
- `PWM_Init()` — 导出 PWM 通道、设置周期/极性/占空比、使能输出
- `set_PWM()` — 设置 PWM 占空比
- `open_boom()` / `close_boom()` — 弹仓开关控制
- 遥控器 5 通道手动控制装弹/卸弹 (rcInCallback)

### 步骤二：fire() 投弹函数 ✅
- `velocity_calculate()` — 计算水平合速度 (cm/s)
- `distance_calculate()` — 经纬度差 → 水平距离 (cm)
- `fire()` 投弹逻辑：
  1. 计算自由落体时间 `sqrt(2h/g)`
  2. 计算投弹延迟 `distance/velocity - fall_time`
  3. `delay ≤ 0` → 立即投弹 `open_boom()`
  4. `0 < delay ≤ 0.3s` → 等待 `delay` 后投弹
  5. 记录投弹状态数据到 buffer
- 在 8~12 号航点以 20Hz 调用
